# Prince Edward 太子

![Prince Edward station name wall](prince-edward.svg)

Hong Kong. An MTR station in Mong Kok, Kowloon, where the Tsuen Wan and Kwun Tong lines meet.

Visited in February 2025 with David and Kurt.

Built in VectorCraft by **Claude Opus 5.5**.

This one isn't a sign panel: it's the station name set into the platform wall's mauve mosaic
tiles. The tiles are generated by [`mosaic.py`](mosaic.py) from colors measured in a photo.
Songti TC and Helvetica Neue stand in for the MTR's lettering.

The editable source is [`prince-edward.vectorcraft`](prince-edward.vectorcraft).
